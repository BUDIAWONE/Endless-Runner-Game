# 🎮 Judul Game: Endless Runner Game
Ini adalah game jenis endless runner di mana pemain mengendalikan sebuah mobil yang bergerak di jalan tanpa akhir sambil mencoba mencapai skor setinggi mungkin. Antarmuka menu sederhana namun fungsional, dengan opsi utama: bermain atau keluar. Game ini tampaknya cocok untuk platform mobile atau desktop ringan.

# 🖼 Tampilan Menu Utama:
- Latar belakang: Jalan lurus mengambang di atas permukaan biru (mungkin laut atau langit).
- Karakter utama: Mobil berwarna hitam-kuning yang siap berada di posisi awal lintasan.

# UI / Antarmuka:
- Tombol "PLAY" berwarna pink: Untuk memulai permainan.
- Tombol "QUIT" berwarna pink: Untuk keluar dari game.

# High Score Display:
- Terdapat ikon permata biru di atas angka (mungkin menggambarkan skor/coin).
- Teks “High Score: 71” ditampilkan di tengah layar.
- Skor tertinggi ditampilkan secara mencolok, menandakan game menyimpan progres pemain.
- Tombol panah ke kiri dan kanan di sisi layar: Kemungkinan digunakan untuk navigasi menu atau kontrol mobil di dalam game.
